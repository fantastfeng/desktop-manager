# 桌面悬浮小框设计

## 目标

把应用做成一个小型、可拖动、半透明的桌面工具窗口，用来整理和打开软件快捷方式、文件和文件夹。

## 窗口形态

- 主窗口无系统边框，并保持半透明效果。
- 顶部标题区域可以拖动，用来移动窗口。
- 默认尺寸应保持紧凑，更接近竖向小抽屉，而不是大面板。
- 窗口保留轻量的最小化和关闭按钮。

## 分类

默认分类为：

- 软件：软件类分类，存放 `.lnk` 快捷方式、`.exe` 程序等软件启动项。
- 文件：文件类分类，存放 Word、PowerPoint、PDF、图片等普通文件。
- 文件夹：文件夹类分类，存放文件夹。

每个分类都有一个“分类类型”，决定它的展示方式和拖拽自动归类规则：

- 软件类：使用图标网格展示，适合应用和快捷方式。
- 文件类：使用详细信息列表展示，适合文档和普通文件。
- 文件夹类：使用详细信息列表展示，适合目录。

分类栏包含一个加号按钮。点击加号后打开简洁的新建分类流程，用户可以输入分类名称，并选择分类类型。因此用户可以新增多个软件类分类，例如“设计软件”“开发软件”“游戏软件”。

分类标签支持用鼠标拖动调整顺序。拖动结束后，新顺序保存到本地，下次打开应用时保持用户调整后的顺序。

## 添加内容

主要添加方式是拖拽：

- 把快捷方式或可执行程序拖入窗口后，自动加入当前排序中第一个软件类分类；默认情况下是“软件”。
- 把普通文件拖入窗口后，自动加入当前排序中第一个文件类分类；默认情况下是“文件”。
- 把文件夹拖入窗口后，自动加入当前排序中第一个文件夹类分类；默认情况下是“文件夹”。
- 拖拽悬停在窗口上方时，窗口显示高亮投放区域，让用户知道可以松手添加。

加号按钮仍保留手动添加入口，但拖拽添加是默认的快速整理方式。

## 展示方式

软件类分类使用图标网格：

- 每个软件项显示图标和名称。
- 点击或双击软件项后启动对应目标。

文件类和文件夹类分类使用类似 Windows 详细信息的列表：

- 列包含：文件名、修改时间。
- 点击“文件名”按文件或文件夹名称排序。
- 点击“修改时间”按修改时间排序。
- 重复点击同一列表头，在升序和降序之间切换。
- 打开文件时，使用系统默认应用打开。
- 打开文件夹时，使用资源管理器打开对应目录。

## 本地持久化

应用在本地保存分类和已添加内容。每条分类记录包含：

- id
- 分类名称
- 分类类型：软件类、文件类或文件夹类
- 排序序号
- 创建时间

每条内容记录包含：

- id
- 分类 id
- 显示名称
- 原始路径
- 内容类型：软件、文件或文件夹
- 可用时保存修改时间
- 可用时保存图标路径
- 创建时间

添加文件和文件夹时，应用不移动用户原始文件，只保存路径引用，并在用户打开时访问该路径。

## 错误处理

- 如果拖入的路径已经不存在，显示简短的内联错误，并保持应用可继续使用。
- 如果打开某个内容失败，显示简短的内联错误。
- 如果一次拖入多个内容，添加所有有效内容，并报告失败项。

## 测试范围

自动化测试需要覆盖：

- 默认分类按“软件、文件、文件夹”的顺序渲染。
- 加号可以新增软件类、文件类或文件夹类分类。
- 分类标签可以通过鼠标拖拽调整顺序，并持久保存新顺序。
- 拖入路径后可以自动分配到第一个匹配类型的分类。
- 文件类和文件夹类以详细信息列表展示，并包含“文件名”和“修改时间”列。
- 点击每个列表头可以切换排序。
- 软件类分类中的内容以图标方式展示。
- Tauri 主窗口配置保持无边框和透明。
